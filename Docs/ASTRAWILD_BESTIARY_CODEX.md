## การใช้งานในเกม (Integration)

- **สัตว์ป่าในโลก**: `AAstrawildWorldBootstrapper` เลือก signature species ประจำโซนวางสปอนตาม `HomeZone` — ดูตาราง `ZoneWildlife` ใน bootstrapper
- **รูปร่างหน้าตา**: `AAstrawildEchoCharacter::BuildProceduralBody()` ประกอบร่างจาก BodyPlan + SizeClass + tints — ไม่ต้องมี art asset ก็แยกออกทันที
- **AI**: ทุกตัววิ่งบน `AAstrawildEchoAIController` เดิม (perception + บุคลิก + activity pattern + weather) — กลางคืน Spirit จะออกล่า กลางวัน Beast เดินหาอาหาร
- **การจับ**: `CaptureComponent` ใช้ CaptureDifficulty + เลือดน้อย + อาหารที่ชอบ + สภาพอากาศตามระบบเดิม
- **งานฐาน**: work affinities เสียบ `WorkSiteActor` ระบบเดิม — Construct เก็บแร่, Flora ทำฟาร์ม, Elemental ผลิตไฟ
- **บอส**: โซน Tidebreaker Isles ใช้ `Echo_Dawnfang` (มังกรน้ำ Serpent Large) เป็นบอสดันเจียนที่ 2 — Sunken Vault
