# ASTRAWILD — Web Playable Slice (Design Validation Prototype)

**สถานะ:** เอกสารอ้างอิง — ต้นแบบที่เล่นได้บนเบราว์เซอร์เพื่อตรวจสอบวงจรการเล่นของ Vertical Slice
**Source of truth:** โมดูล `AstrawildCore` (C++) ยังคงเป็นผู้กำหนดกติกาที่แท้จริง เว็บต้นแบบนี้ใช้เพื่อการตัดสินใจด้านดีไซน์ก่อนนำไปสร้างคอนเทนต์ใน Unreal Editor

## เหตุผล

เอกสาร `PLAN.md` กำหนดว่า Vertical Slice (M1) ต้องพิสูจน์วงจร "movement → interaction → harvest →
inventory → damage → capture → craft → rest point → save/load" ให้เล่นจบหนึ่งรอบได้ก่อนขยายโลก
เนื่องจากการคอมไพล์ Unreal ต้องทำบนเครื่องเป้าหมาย Windows จึงสร้างต้นแบบเว็บที่เล่นได้ทันที
เพื่อทดสอบความสนุกและสมดุลของกติกาก่อน แล้วจึงถ่ายโอนค่าที่ผ่านการทดสอบกลับเข้า Data Assets

## สิ่งที่ต้นแบบเว็บครอบคลุม (อิงจากเอกสารออกแบบ)

| ระบบ | อ้างอิงเอกสาร | หมายเหตุ |
|---|---|---|
| สำรวจทุ่งอรุณ (แผนที่เดียว ขนาดย่อม) | game_design §2 | ทุ่งหญ้า ป่าโปร่ง ทะเลสาบ ซากสถานีโบราณ |
| สถานะการเอาชีวิตรอด (พลังชีวิต ความอึด ความหิว ความกระหาย) | gameplay §3 | ลดช้า ไม่สร้างภาระในพื้นที่ปลอดภัย |
| การต่อสู้ (โจมตี หลบ มี telegraph) | gameplay §4 | ศัตรูหนีเมื่อเลือดต่ำ ตกใจเมื่อฝูงถูกทำร้าย |
| การจับ 2 เส้นทาง: ทำให้อ่อนแรง / สร้างความไว้ใจด้วยอาหาร | gameplay §5 | สูตรโอกาสจับตรงกับ `ComputeCaptureChance()` ใน C++ |
| ความไว้ใจ 5 ระดับ (รู้จัก → คู่หู) | gameplay §6 | ส่งผลต่อความสามารถร่วมทีม |
| อีโค 8 สายพันธุ์ของทุ่งอรุณ พร้อมธาตุ/บทบาท/บุคลิก/อาหารโปรด | game_design §2, §4 | พร้อมสมุดภาคสนามที่ค่อย ๆ เปิดข้อมูล |
| ทรัพยากร + คราฟต์ (เครื่องรักคลื่น อาหาร ยา อัปเกรดอาวุธ) | gameplay §8 | ขับเคลื่อนด้วยข้อมูล (data-driven) ทั้งหมด |
| จุดพัก (Rest Point) + เซฟ/โหลด พร้อม schema version และ backup | gameplay §11 | Auto-save, manual save ที่แคมป์, ตรวจสอบเวอร์ชัน |
| เควสต์หลัก 5 ตอน + บอสผู้พิทักษ์ 3 เฟส | game_design §2, gameplay §4 | บอสเปลี่ยนกติกาตามเฟส ไม่ใช่เพิ่มเลือดอย่างเดียว |
| อีโคคู่หูภาคสนาม (สูงสุด 3 ตัว) ช่วยต่อสู้ตามระดับความไว้ใจ | gameplay §4 | 1 ตัวติดตัวในต้นแบบเว็บ |

## ค่าที่แนะนำให้ถ่ายโอนกลับเข้า Unreal Data Assets หลังการทดสอบ

- `CaptureResilience` ต่อสายพันธุ์ (ค่าเริ่มต้น 0.35 ใน C++)
- อัตราความหิว/กระหาย ต่อนาทีของการเล่น
- ความเสียหาย/พลังชีวิตของอีโคแต่ละสายพันธุ์ และบอส
- ราคาวัตถุดิบของสูตรคราฟต์

## ข้อจำกัดของต้นแบบเว็บ

- มุมมองจากด้านบนแทนมุมมองบุคคลที่สาม (ยืนยันวงจรการเล่น ไม่ใช่ภาพและกล้อง)
- ไม่มี Co-op, ไม่มีระบบเสียง 3D, ไม่มี Nanite/Lumen
- ใช้กระดานผู้นำคะแนนผ่านฐานข้อมูลเพื่อทดสอบแรงจูงใจในการเล่นซ้ำเท่านั้น
